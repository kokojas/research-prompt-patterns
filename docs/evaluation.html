Design

Controls match the workflow

The analysis and question-expansion prompts use the plain one-turn request as control. The clarification prompt uses a two-turn control that receives the same facts in the second user message.

All generation runs use Oracle 0.21.3, OpenAI API, GPT-5.6 Sol, high effort, standard mode. Oracle's browser path failed model-picker verification, so these findings are not automatically claims about the ChatGPT interface.
